# PRACTICE NOTE

女子バレー部の練習ノート。部員が練習・試合のあとにスマホで書き、顧問が一言返す。
試合のレポートやジャンプ測定の推移も、ここで見られる。

公開ページ：https://slothfront.github.io/practice-note/
（ホーム画面に追加するとアプリのように使える。一度開けば電波が無くても開ける。2回目からは前の控えをすぐに出し、新しい版は裏で取ってきて入れ替わる＝電波が弱くても真っ白で待たない）

## 部員の画面

| タブ | できること |
|---|---|
| 今日の記録 | 練習／試合／**自主練**を選んで書く（自主練＝やったこと・時間〈分〉・気づいたこと。グラフのタブに今週・今月の自主練の時間）。練習・試合はFOCUS（前回のNEXTが入る）・数字（意識できた・体の調子・気持ちを1〜5）・ふり返り・NEXT。**DATE で日付を変えると、書き忘れた前の日の分もあとから書ける**（先の日付は不可）。最後に **「顧問に見せる」か「自分だけに残す」** を選ぶ（ノートは評価のためではないので）。自分だけにすると、顧問の画面には日付・練習／試合・数字だけが出る（中身は表には残るが、GASが消してから顧問に渡す）。あとから「顧問に見せる」にもできる。電波が無いときは端末に置いて、つながったら送る。練習・試合では **仲間のよかったこと（TEAM GOOD）** も書ける（書かなくてもOK・3人まで。だれのことかを選んで、何をしていたかを書く）。顧問が読んで「本人に届ける」を押すと、書いた人の名前つきで本人に届き、今日の記録の上に出る |
| これまで | いちばん上に「もらったGOOD」。自分の記録と顧問の返事（書いた仲間のGOODが届いたかも出る）。言葉でさがす・★だけ・「気づき」（言われたこと・課題だけを抜き出す）。あとから書いた記録には「（○/○に記入）」 |
| グラフ | 数字の推移・1や2を付けた日・ジャンプ測定（最高到達点・跳躍高・垂直跳び。自分と全員・先輩のベストを参考線で） |
| レポート | 顧問が送った試合レポート（チーム・自分）。いちばん新しい試合も、たたんで閉じられる |
| お知らせ | 顧問からのお知らせを **未読／既読** に分けて表示。「既読にする」で既読へ移る |
| 予定 | 顧問のGoogleカレンダー「部活」の予定（3週間先まで）。名前・日付・時刻・場所だけで、説明欄は出さない。名前に「顧問」が入る予定・頭に🔒の予定は出さない。誕生日は名前だけ出す（括弧の中のフルネームは消す）。今日と明日の予定は「今日の記録」の一番上にも出る |

## 顧問の画面（紫）

| タブ | できること |
|---|---|
| ホーム | 上から 今日と明日の予定 → 今日の記録 n／人数（書いた人・まだの人） → 昨日の記録（同じ形） → 仲間のGOOD 確認待ち（あるときだけ。「本人に届ける」／「届けない」・まとめて届ける） → 返事を待っている記録。部員の新しい記録に返事を書く。体の調子・気持ちなどに1か2がある記録は黄色の線。「自分だけ」の記録は日付と数字だけ出て、返事は付けられない |
| 部員ごと | 部員ひとりずつの記録と「最後に開いた」日時・仲間のGOOD（もらった・書いた）。いちばん上に「ここ2週間、仲間のGOODに名前が出ていない部員」（部員には見えない）（はじめの合言葉のままなら、その印も）。「この部員の画面で見る」で部員にどう見えるかを確かめられる（見るだけ・書き込みはしない） |
| お知らせ | 全員・学年・1人に送る。だれが読んだか（既読 n／m）が分かる。書いた顧問だけが直す／消す |
| 予定 | 部員のアプリに出ている予定（3週間先まで）
| 試合と測定 | 上の切りかえで「試合レポート」と「ジャンプ測定」。試合レポート＝フジ子が作ったレポートのファイル（`.json`）を読み込み、確かめてから送る。送ったものはここでも見られる |
| （試合と測定）ジャンプ測定 | 測定を入れる（入力欄はたためる）・ファイルからまとめて読み込む・測定日ごとに直す／消す |
| 顧問 | 顧問どうしのメモ（全体あて／部員ごと）。部員には見えない |

見出しは英語＋日本語で、いつも白い四角の上に置く（中身だけを白い四角に入れる）。

## デザイン

- 部員の画面＝くすみピンク×ワイン（トレーナーの色案C7）、顧問の画面＝ラベンダーグレー×ネイビー（C9）
- 上の帯はシンプル（PRACTICE NOTE と日付・名前だけ）
- 背景に部のボールを大きくうすく（`bg-ball-*.png`）。カードは少しすかす
- ホーム画面のアイコン＝白いボール＋KCVC（ワイン地）。英字の見出しと数字は Teko（見出しは大きく斜めにピンクの影）、日本語は Noto Sans JP
- どの画面もいちばん下に、背中のロゴ（KIMITSU COMMERCIAL HS／KCVC／VOLLEYBALL CLUB／一文）（`plate-*.png`・板は無しで文字だけ）

## ファイル

- `index.html`：アプリ本体（部員と顧問の画面。合言葉で切り替わる）
- `sw.js`：電波が無くても・弱くても開けるようにする仕組み（サービスワーカー）。ページは控えを先に出し、最新は裏で取る。記録の送受信には触らない
- 字（Google Fonts）は読み込みを待たずに画面を出す（届いたら字が切り替わる）。控えの無い初めての人には「読み込み中…」が出る
- `manifest.webmanifest`・アイコン類・`plate-*.png`・`bg-ball-*.png`：ホーム画面に追加したときの名前と絵、いちばん下のロゴ、背景のボール
- `gas/Code.gs`：記録をためるGoogleの表とのやり取り（Google Apps Script）
- `gas/appsscript.json`：GASの設定（タイムゾーン・ウェブアプリの公開範囲・使う許可＝表とカレンダーの読み取り）
- `gas-updater/`：GASを自動で入れ替える「更新係」（別のスクリプト）

## しくみ

- **GitHub Pages**：画面（`index.html`）を配る。`main` に入ると数分で公開ページが新しくなる
- **GAS＋Googleの表**：記録・返事・お知らせなどをためる。合言葉の確かめもここ。
  シート＝部員・記録・返事・お知らせ・既読・レポート・ジャンプ・顧問メモ・顧問既読・仲間のGOOD（足りないシートや列は呼ばれたときに自動で作る）
- `index.html` の `GAS_URL` が空のあいだは見本モード（端末の中だけで動く）

### GASの自動更新

`main` の `gas/`（`Code.gs`・`appsscript.json`）が変わると、GitHub Actions（`.github/workflows/gas-update.yml`）が
別のスクリプト **「更新係」**（`gas-updater/`）に合図する。更新係が同じコミットの `gas/` を本体のGASに入れ、新しいバージョンでデプロイし直す（本体のURLは変わらない）。
Apps Script API を使うのは更新係だけで、自分の Google Cloud プロジェクトにつなぐのも更新係だけ。本体のGASは既定のままなので、更新係が止まってもアプリは止まらない。

- 更新係の置き場：script.google.com の別のプロジェクト「PRACTICE NOTE 更新係」（`gas-updater/Code.gs`・`appsscript.json` を手で貼る。自動では更新されない）
- Secrets：`GAS_UPDATER_URL`（更新係のウェブアプリのURL）・`GAS_UPDATE_TOKEN`（更新係で `makeUpdateToken` を実行するとできる）
- 結果：Actions の実行記録に「結果：…」と出る。手で動かすとき＝更新係で `updateNow`
- 形のおかしいコード・受け口でないコードには入れ替えない。戻すとき＝本体の「デプロイを管理」で前のバージョンを選ぶ
- 本体の使う許可（`gas/appsscript.json` の `oauthScopes`）を増やすときは、自動では許可されないので、本体のエディタで1回実行して許可する
- 前提：[Apps Scriptの設定](https://script.google.com/home/usersettings)で「Google Apps Script API」がオン。バージョンは1つのスクリプトで200まで

### バックアップと代の切り替え

- **バックアップ**：アプリが使われたとき、前から7日たっていれば表の写し「PRACTICE NOTE 記録_バックアップ_YYYYMMDD_HHMM」を作る（マイドライブ直下にでき、Drive整理が `03_部活/練習/PRACTICE NOTE バックアップ` へ移す）。手で＝GASのエディタで `backupNow`
- **代の切り替え**：引退する学年が決まったら、GASのエディタで `retireGrade3`（3年生がいない年は `retireGrade2`）を実行。部員シートの「役割」が「引退」になり、顧問の画面・人数・お知らせの宛先から外れる。本人は自分の記録を見られる。ジャンプは「○○のベスト」として参考線に残る。もどすときは「役割」を `student` に
- **4月**：`nextSchoolYear` で、引退していない部員の学年を1つ上げる。新入部員は「部員」シートに1行足して `makeKeys`
- どれも先にバックアップを取る

### GASを入れ直すとき

1. `gas/Code.gs` をスクリプトに貼る（はじめてのときだけ `setupPracticeNote` を1回実行して表を作る）
2. 「デプロイを管理」→ いまのデプロイを編集 → 新しいバージョン（URLは変わらない）
3. 部員を足したときは「部員」シートに1行足して `makeKeys` を実行（はじめの合言葉が入る。顧問は役割を `coach` に）

画面（`index.html`）だけの変更なら、GASの貼り替えは要らない。

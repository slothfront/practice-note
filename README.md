# PRACTICE NOTE

女子バレー部の練習ノート。部員が練習・試合のあとにスマホで書き、顧問が一言返す。
試合のレポートやジャンプ測定の推移も、ここで見られる。

公開ページ：https://slothfront.github.io/practice-note/
（ホーム画面に追加するとアプリのように使える。一度開けば電波が無くても開ける）

## 部員の画面

| タブ | できること |
|---|---|
| 今日の記録 | 練習／試合を選んで書く。FOCUS（前回のNEXTが入る）・数字（意識できた・体の調子・気持ちを1〜5）・ふり返り・NEXT。**DATE で日付を変えると、書き忘れた前の日の分もあとから書ける**（先の日付は不可）。最後に **「先生に見せる」か「自分だけに残す」** を選ぶ（ノートは評価のためではないので）。自分だけにすると、顧問の画面には日付・練習／試合・数字だけが出る（中身は表には残るが、GASが消してから顧問に渡す）。あとから「先生に見せる」にもできる。電波が無いときは端末に置いて、つながったら送る |
| これまで | 自分の記録と顧問の返事。言葉でさがす・★だけ・「気づき」（言われたこと・課題だけを抜き出す）。あとから書いた記録には「（○/○に記入）」 |
| グラフ | 数字の推移・1や2を付けた日・ジャンプ測定（最高到達点・跳躍高・垂直跳び。自分と全員・先輩のベストを参考線で） |
| レポート | 顧問が送った試合レポート（チーム・自分）。いちばん新しい試合も、たたんで閉じられる |
| お知らせ | 顧問からのお知らせを **未読／既読** に分けて表示。「既読にする」で既読へ移る |

## 顧問の画面（紫）

| タブ | できること |
|---|---|
| 新しい記録 | 部員の新しい記録に返事を書く。体の調子・気持ちなどに1か2がある記録は黄色の線。「自分だけ」の記録は日付と数字だけ出て、返事は付けられない |
| 部員ごと | 部員ひとりずつの記録。「この部員の画面で見る」で部員にどう見えるかを確かめられる（見るだけ・書き込みはしない） |
| お知らせ | 全員・学年・1人に送る。だれが読んだか（既読 n／m）が分かる。書いた先生だけが直す／消す |
| レポート | フジ子が作ったレポートのファイル（`.json`）を読み込み、確かめてから送る。送ったものはここでも見られる |
| ジャンプ | 測定を入れる（入力欄はたためる）・ファイルからまとめて読み込む・測定日ごとに直す／消す |
| 顧問 | 顧問どうしのメモ（全体あて／部員ごと）。部員には見えない |

見出しは英語＋日本語で、いつも白い四角の上に置く（中身だけを白い四角に入れる）。

## ファイル

- `index.html`：アプリ本体（部員と顧問の画面。合言葉で切り替わる）
- `sw.js`：電波が無くても開けるようにする仕組み（サービスワーカー）。記録の送受信には触らない
- `manifest.webmanifest`・アイコン類：ホーム画面に追加したときの名前と絵
- `gas/Code.gs`：記録をためるGoogleの表とのやり取り（Google Apps Script）
- `gas/appsscript.json`：GASの設定（タイムゾーン・ウェブアプリの公開範囲・使う許可）

## しくみ

- **GitHub Pages**：画面（`index.html`）を配る。`main` に入ると数分で公開ページが新しくなる
- **GAS＋Googleの表**：記録・返事・お知らせなどをためる。合言葉の確かめもここ。
  シート＝部員・記録・返事・お知らせ・既読・レポート・ジャンプ・顧問メモ・顧問既読（足りないシートや列は呼ばれたときに自動で作る）
- `index.html` の `GAS_URL` が空のあいだは見本モード（端末の中だけで動く）

### GASの自動更新

`main` の `gas/`（`Code.gs`・`appsscript.json`）が変わると、GitHub Actions（`.github/workflows/gas-update.yml`）がGASに合図し、
GASが同じコミットのコードを自分で取り込んで、新しいバージョンでデプロイし直す（`selfUpdate_`・URLは変わらない）。
結果は表の「更新」シートに1行ずつ残る。形のおかしいコードや、自動更新の仕組みが入っていないコードには入れ替えない。

- 合図の合言葉：GASの `makeUpdateToken` を実行 → ログの1行を GitHub の Secrets「GAS_UPDATE_TOKEN」へ
- 手で取り込むとき：GASのエディタで `updateFromGitHub` を実行
- 戻すとき：「デプロイを管理」で前のバージョンを選ぶ
- 使う許可（`appsscript.json` の `oauthScopes`）を増やすときは、自動では許可されないので、エディタで1回実行して許可する
- 前提：[Apps Scriptの設定](https://script.google.com/home/usersettings)で「Google Apps Script API」がオン。バージョンは1つのスクリプトで200まで

### GASを入れ直すとき

1. `gas/Code.gs` をスクリプトに貼る（はじめてのときだけ `setupPracticeNote` を1回実行して表を作る）
2. 「デプロイを管理」→ いまのデプロイを編集 → 新しいバージョン（URLは変わらない）
3. 部員を足したときは「部員」シートに1行足して `makeKeys` を実行（はじめの合言葉が入る。顧問は役割を `coach` に）

画面（`index.html`）だけの変更なら、GASの貼り替えは要らない。

## 守ること

- このリポジトリは公開。**部員の名前・記録・レポートの中身・合言葉は置かない**（それらはGoogleの表とレポートのファイルの中だけ）
